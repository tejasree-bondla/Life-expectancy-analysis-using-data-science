# Life Expectancy Analysis

A Data Science project that analyzes global life expectancy data to identify the factors that influence life expectancy using Python and machine learning techniques.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib
- Correlation analysis
- Machine Learning model for prediction
- Performance evaluation using regression metrics

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses a Life Expectancy dataset containing demographic, economic, and health-related indicators from different countries.

## Workflow
1. Import the dataset.
2. Clean missing and inconsistent values.
3. Perform exploratory data analysis.
4. Visualize relationships between variables.
5. Train and evaluate a machine learning model.
6. Interpret the results.

## Results
The project identifies important factors such as adult mortality, GDP, schooling, and healthcare indicators that significantly affect life expectancy.
